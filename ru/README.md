# Factor0x — Русская версия

Этот каталог содержит русскую версию сайта Factor0x.

## Содержимое

| Путь | Описание |
|------|----------|
| `index.html` | Главная страница |
| `legal/` | Юридические документы (в разработке) |

## Общие ресурсы

CSS, JavaScript, шрифты, изображения и видео расположены в родительских директориях:

- `../css/` — Стили (`site.css`, `main.css`, `popup.css`)
- `../js/` — Скрипты (`marketplace.js`, `en-features.js`, `site.js`, `popup.js`, `cookie.js`)
- `../resources/` — Шрифты, изображения, иконки, видео, логотип

Предзагрузка шрифтов на этой странице использует **кириллические** варианты woff2:
`../resources/fonts/normal/cyrillic/normal-regular.woff2`
`../resources/fonts/normal/cyrillic/normal-semibold.woff2`

## Метаданные языка

- `lang="ru"`
- Canonical: `https://factor0x.bitilia.com/ru/`
- hreflang: `en`, `ru`, `x-default → en`

## Примечания

- Строки версий ресурсов (`?v=demo3`) используются для сброса кеша браузера.
- Система локализации (`js/i18n.js`) считывает атрибут `<html lang>` при загрузке и применяет соответствующий словарь из `js/locales/`.
- Скрипт `en-features.js` является основным модулем функциональности страницы; он автоматически использует русскую локаль благодаря системе i18n.
